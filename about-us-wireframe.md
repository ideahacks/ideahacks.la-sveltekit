## Design Specifications

### Color Scheme
- Primary: Blue gradient background (matching existing site)
- Text: White on blue sections, dark gray on white sections
- Accent: Yellow for CTAs (matching existing brand colors)

### Typography
- Headers: Encode Sans, bold weights
- Body: Encode Sans, regular weight
- Consistent with existing site typography

### Layout Principles
1. **Full-width sections** with proper padding
2. **Centered content** with max-width constraints
3. **Visual hierarchy** through font sizes and spacing
4. **Card-based design** for sponsor benefits
5. **Responsive design** for mobile compatibility

### Interactive Elements
- Smooth scroll navigation
- Hover effects on buttons and cards
- Fade-in animations for sections
- Ripple effects on clickable elements

### Content Organization
1. **Hero Section**: IEEE at UCLA introduction
2. **IEEE Section**: Organization details and contact
3. **IDEA Hacks Section**: Event description
4. **Theme Section**: Current year's theme and tracks
5. **Sponsor Benefits**: Three-column card layout
6. **CTA Section**: Clear action items
7. **Footer**: Standard site footer

### Mobile Considerations
- Stack cards vertically on mobile
- Reduce font sizes appropriately
- Maintain touch-friendly button sizes
- Ensure proper spacing for readability

This wireframe provides a comprehensive structure for the about us page that maintains consistency with the existing site design while effectively presenting all the provided content in a logical, visually appealing manner.
